# Math 5520H

Materials for a combined honors linear algebra and differential equations course
taught at Ohio State University (Autumn 2026).

PDFs for the problem sets are built automatically by CI and deployed to
**[kisonecat.github.io/math5520h](https://kisonecat.github.io/math5520h/)**.
